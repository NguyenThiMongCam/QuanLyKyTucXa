# Quản lý ký túc xá (Python + Tkinter + SQLite)

Chạy: `python main.py` (Python 3.9+, không cần cài thêm thư viện).
Lần đầu chạy sẽ tự tạo file `kytucxa.db` kèm dữ liệu mẫu.

Tài khoản: admin / admin123 (quản trị) — nhanvien / 123456 (nhân viên)

Sinh viên: chọn "SINH VIÊN", nhập mã sinh viên (cột MaSV, ví dụ 1) và mật khẩu mặc định 123456.
Chọn đúng tình trạng ký túc xá (đang ở = có hợp đồng "Đang thuê").
